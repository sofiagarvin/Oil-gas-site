About This Website

This website serves to explain the key operational stages of the oil and gas industry, as well as provide a terminology page to help people understand key terms and definitions in this industry.

The chatbot streamlines the process of finding the definition of a specific word and understanding its context. Instead of searching across multiple sources, users can immediately retrieve concise explanations directly within the site.

Additional Feature: Value Chain Explorer

The Value Chain Explorer is an interactive feature designed to enhance user engagement and understanding. Rather than presenting static descriptions of upstream, midstream, and downstream operations, the Explorer allows users to hover over or select each segment to dynamically view:

  • A concise explanation of the segment’s operational role
  • Key assets associated with that stage
  • Primary value drivers
  • Core performance metrics (KPIs)

This feature transforms the website from a purely informational resource into an interactive learning tool. It improves usability, increases engagement, and helps users build a structured mental model of how hydrocarbons move from rock to market.
